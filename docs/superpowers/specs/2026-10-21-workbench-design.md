# 科然数智首版设计

用户已同意先在本地开发、使用 GitHub 管理代码、接近上线时购买服务器。目标用户是公司内部 10～30 人。参考网站的登录页、老板工作台、模块导航和财务页面目录已只读查看。参考账号只用于查看，不复制账号、业务数据或源代码。

## 范围与方案

第一阶段交付独立可运行的经营工作台，而非宣称完整复制原站全部模块。包括首次建立管理员、会话登录退出、管理员/只读角色、经营驾驶舱、交易明细筛选分页、CSV 预检与原子导入、导入历史、用户管理。管理员可以主动加载合成演示数据，页面始终标明演示数据。视觉沿用参考站的深色导航、暖白背景和金色强调色。不开发空壳业务模块。

采用 React + Vite 前端，Node 24 HTTP 服务与内置 SQLite 数据库。相比纯静态原型，支持真实权限和持久化；相比立即采用多服务架构，部署和备份简单。首期 4 核 8GB 单机即可起步，实际容量以后通过真实数据测试评估。数据层与核算层独立，后续可迁移 PostgreSQL。

## 数据与核算

每行是每日店铺商品经营记录：日期、渠道、店铺、商品、销售额、退款额、产品成本、广告费、平台费、运费。金额入库为分的整数。净销售额=销售额-退款额；毛利=净销售额-产品成本；预估净利=毛利-广告费-平台费-运费。毛利率和净利率分母为净销售额，分母为零显示零。财务计算口径在界面展示。

日期、渠道筛选同时作用于指标、趋势和排名；环比按等长上一周期计算，无前期基数则显示暂无对比。自然键为日期+渠道+店铺+商品；重复记录拒绝整批导入，避免静默覆盖。CSV 最大 5MB、最多 10000 行，强制校验表头、真实日期、金额范围，公式文本拒绝，出错不写入部分数据。模板使用 UTF-8 BOM 便于 Excel 打开。

## 身份、安全与运行

密码用 scrypt 加盐哈希，仅存储会话 token 的哈希。HttpOnly + SameSite Cookie，生产环境 Secure；会话七天到期。所有变更接口检查 Origin，后台强制角色权限；登录限流。首次初始化仅限本地或生产环境配置的随机 SETUP_TOKEN。开发不复用参考站密码。生产模式必须配置 PUBLIC_ORIGIN、SETUP_TOKEN，前置 HTTPS 反向代理。

数据库和密钥不提交；GitHub Actions 执行依赖安装、测试、检查、构建。提供 Docker、部署说明和数据库备份命令。首版不公开部署、不购买服务器。

## 验收

自动测试覆盖核算金额、日期范围、导入原子性、重复行、未认证访问、只读角色越权、Origin 防护、登录退出、持久化。生产构建成功，并在浏览器验证初始化、驾驶舱、筛选、导入预检和权限。GitHub 同步需要本机有效身份；如受阻，保留已提交的本地代码，明确说明状态。
